# Homebrew Sidebrief Tap

Official Homebrew tap for [Sidebrief](https://github.com/KevinOBytes/sidebrief) — the native macOS meeting copilot.

## Installation

Install directly via one command:

```bash
brew install KevinOBytes/sidebrief/sidebrief
```

Or tap the repository first:

```bash
brew tap KevinOBytes/sidebrief
brew install --cask sidebrief
```

## Updating

```bash
brew upgrade --cask sidebrief
```

## Uninstalling

```bash
brew uninstall --cask sidebrief --zap
```
